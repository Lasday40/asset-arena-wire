# Asset Arena Wire

The press release wire built for sports business. A static site on GitHub Pages, generated by `build.py` from JSON files in `releases/`.

## How it works

1. A company submits a release on `/submit/`. The form posts to a Google Apps Script web app, which appends a row (status `Pending`) to the submissions Sheet and emails David.
2. David reviews the row. If approved, he invoices ($199 per release, or $1,200 per year for a Founding Member).
3. Once paid, he selects the row and uses **Asset Arena Wire > Generate release JSON for selected row** in the Sheet, then saves the output as `releases/YYYY-MM-DD-slug.json`.
4. Pushing to `main` runs `.github/workflows/deploy.yml`, which validates every release, builds the site into `_site/` and deploys it to Pages.

## Repo layout

| Path | What it is |
| --- | --- |
| `config.json` | Site name, base URL, submit endpoint, categories, pricing plans |
| `releases/*.json` | One file per press release |
| `build.py` | Validates releases and generates the site (Python standard library only) |
| `assets/` | Stylesheet, logo, headshot |
| `apps-script/Code.gs` | Submission handler and review helper for the Google Sheet |

## Release format

```json
{
  "slug": "acme-raises-5m-seed",
  "status": "published",
  "date": "2026-11-20",
  "dateline": "NEW YORK",
  "category": "Investment & Capital",
  "organization": { "name": "Acme Sports", "url": "https://example.com" },
  "founding_member": false,
  "headline": "Acme Sports Raises $5M Seed Round",
  "subheadline": "Optional one sentence summary.",
  "body": ["First paragraph.", "Second paragraph. **Bold** and [links](https://example.com) work."],
  "about": [{ "name": "Acme Sports", "text": "Boilerplate." }],
  "contact": { "name": "Jane Doe", "organization": "Acme Sports", "email": "press@example.com", "phone": "" },
  "tags": ["seed round"],
  "image": { "src": "images/2026-11-20-acme-raises-5m-seed.jpg", "alt": "Acme Sports founders", "caption": "Photo courtesy of Acme Sports" }
}
```

`image` is optional. Put the file in `releases/images/` (JPG, PNG or WebP). It shows on the release page, as a thumbnail in lists, and as the LinkedIn preview image. Images uploaded through the form are saved to the "Asset Arena Wire Images" folder in Drive, with the link in the Sheet's Image column.

`status` is `published` or `draft`. The category must match one in `config.json`. The build fails on missing fields, duplicate slugs, bad dates, or any em or en dash.

## Local preview

```bash
python3 build.py --drafts
python3 -m http.server -d _site 8000
```

## One time setup

1. **Pages:** Settings > Pages > Source: **GitHub Actions**.
2. **Form:** follow the steps at the top of `apps-script/Code.gs`, then paste the web app URL into `config.json` as `submit_endpoint`. Until then the form tells visitors to email their release instead.
3. **Custom domain:** assetarenawire.com, registered and DNS hosted at Cloudflare (4 A records to GitHub Pages IPs, www CNAME to lasday40.github.io, DNS only). Set in Settings > Pages > Custom domain, with `base_url` in `config.json` and the `CNAME` file matching.
