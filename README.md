# Asset Arena Wire

The press release wire built for sports business. A static site on GitHub Pages, generated by `build.py` from JSON files in `releases/`.

## How it works

1. A company submits a release on `/submit/`. The form posts to a Google Apps Script web app, which appends a row (status `Pending`) to the submissions Sheet and emails David.
2. David reviews the row and sets **Status** (dropdown: Pending, Approved, Rejected, Published). Payment is tracked separately in the **Payment** column (Not invoiced, Invoiced, Paid, Waived) with the date in **Paid on**. Invoices are $199 per release, or $1,200 per year for a Founding Member.
3. Once a row is Approved (normally after Payment is Paid), he selects the row and uses **Asset Arena Wire > Publish selected row**. After a confirmation dialog it checks the row against the same rules as `build.py`, commits the release JSON (and the image from Drive, if any) to `main` in one commit, sets Status to `Published` and fills in the Published URL. Editing a Published row and publishing again updates the live release at the same URL. **Preview release JSON** shows the file without publishing.
4. Pushing to `main` runs `.github/workflows/deploy.yml`, which validates every release, builds the site into `_site/` and deploys it to Pages.

## Repo layout

| Path | What it is |
| --- | --- |

## Release format

```json
{
  "slug": "acme-raises-5m-seed",
  "status": "published",
  "date": "2026-11-20",
  "dateline": "NEW YORK",
  "category": "Investment & Capital",
  "organization": { "name": "Acme Sports", "url": "https://example.com" },
  "founding_member": false,
  "headline": "Acme Sports Raises $5M Seed Round",
  "subheadline": "Optional one sentence summary.",
  "body": ["First paragraph.", "Second paragraph. **Bold** and [links](https://example.com) work."],
  "about": [{ "name": "Acme Sports", "text": "Boilerplate." }],
  "contact": { "name": "Jane Doe", "organization": "Acme Sports", "email": "press@example.com", "phone": "" },
  "tags": ["seed round"],
  "image": { "src": "images/2026-11-20-acme-raises-5m-seed.jpg", "alt": "Acme Sports founders", "caption": "Photo courtesy of Acme Sports" }
}
```

`image` is optional. Put the file in `releases/images/` (JPG, PNG or WebP). It shows on the release page, as a thumbnail in lists, and as the LinkedIn preview image. Images uploaded through the form are saved to the "Asset Arena Wire Images" folder in Drive, with the link in the Sheet's Image column.

`status` is `published` or `draft`. The category must match one in `config.json`. The build fails on missing fields, duplicate slugs, bad dates, or any em or en dash.

## LinkedIn commentary (posts/)

`posts/linkedin.json` holds David's LinkedIn posts, each with `date`, `category`, `excerpt` (the post's opening hook) and `url`. They show on each category page under "From the Asset Arena desk", labeled as commentary, and add a post count to the homepage category tiles. They are never published as releases, so the approval rule for releases is unaffected. To add posts, append entries to the file (or add another JSON file in `posts/`, one object or a list).

## Feeds, sitemaps and syndication

Each build writes:

- `feed.xml`: all releases, full text with images (`content:encoded`, `media:content`), for feed readers and syndication partners.
- `category/<slug>/feed.xml`: one feed per category, so a youth sports newsletter can pull only Youth Sports.
- `feeds/`: public page listing every feed with republishing terms. Point partners here.
- `sitemap.xml` with `lastmod`, and `news-sitemap.xml` (Google News format, releases from the last two days only). Both are listed in `robots.txt`.

The workflow rebuilds daily so the news sitemap drops releases older than two days. Release pages carry `NewsArticle` structured data with publisher logo and image.

One time: add assetarenawire.com in Google Search Console (Cloudflare DNS TXT verification), submit both sitemaps, then add the site in Google News Publisher Center.

## One time setup

1. **Pages:** Settings > Pages > Source: **GitHub Actions**.
2. **Form:** follow the steps at the top of `apps-script/Code.gs`, then paste the web app URL into `config.json` as `submit_endpoint`. Until then the form tells visitors to email their release instead.
3. **One-click publish:** the Sheet menu needs this file in the Sheet's own script (Extensions > Apps Script, project "Asset Arena Wire Sheet menu"). The standalone "Asset Arena Wire Form" project runs the form endpoint; keep both on the same Code.gs. Then create a fine grained GitHub token (github.com/settings/personal-access-tokens) with access to only this repo and **Contents: Read and write**, then in the Sheet use **Asset Arena Wire > Set GitHub token** and paste it. The token is stored in the script's properties, never in the Sheet.
4. **Custom domain:** assetarenawire.com, registered and DNS hosted at Cloudflare (4 A records to GitHub Pages IPs, www CNAME to lasday40.github.io, DNS only). Set in Settings > Pages > Custom domain, with `base_url` in `config.json` and the `CNAME` file matching.
